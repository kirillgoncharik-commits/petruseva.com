# Карта сайта

| URL | Роль страницы | Основное действие |
| --- | --- | --- |
| `/` | Позиционирование, жизненные контексты, форматы, доверие, цены | Записаться |
| `/individual-therapy/` | Индивидуальная терапия для взрослых 18+ | Записаться на индивидуальную встречу |
| `/couples-therapy/` | Терапия для пар и семейная консультация | Записаться вдвоём |
| `/emigration-adaptation/` | Поддержка при переезде и адаптации | Выбрать индивидуальный или парный формат |
| `/about/` | Образование, сертификация, подход, профессиональный путь | Познакомиться с форматом работы |
| `/articles/` | Тематический хаб без искусственно сгенерированных статей | Перейти к релевантной услуге |
| `/contact/` | Каналы записи, формат и стоимость первой встречи | Написать в WhatsApp или Telegram |
| `/privacy` | Политика конфиденциальности | — |

Pricing интегрирован в главную и страницы услуг. Отдельная тонкая SEO-страница `/pricing/` не нужна.
