# UI refresh

## Визуальный тезис

Спокойный личный editorial-сайт: много воздуха, тёплая бумажная основа, глубокий зелёный текст, мягкий сиреневый акцент, выразительная антиква Fraunces и нейтральный Inter. Существующие фотографии и палитра сохраняются.

## Компоненты

- Primary button: плоская заливка, высота 48–50 px, радиус 10 px, без градиента и сильной тени.
- Secondary button: спокойный outline/text style.
- CTA: один главный текст «Записаться на консультацию»; каналы связи раскрываются на странице контактов.
- Cards: только для двух форматов терапии и двух тарифов. Жизненные контексты, этапы и trust facts строятся на сетке и разделителях.
- Forms: не добавляются без рабочего обработчика и отдельного согласия на сбор данных.
- Spacing: 88–120 px между крупными desktop-секциями, 64–80 px на мобильных.
- Focus: контрастный двухпиксельный outline; touch-target не меньше 44 px.
- Motion: короткие hover/focus-переходы; `prefers-reduced-motion` отключает анимацию.

## Адаптивность

Split hero превращается в один столбец; фотография остаётся в первом экране. Навигация сворачивается в доступное меню. Сетки форматов и цен становятся одноколоночными без горизонтального скролла.
