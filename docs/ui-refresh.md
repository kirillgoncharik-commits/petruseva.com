# UI refresh

## Визуальный тезис

Обновление продолжает визуальную ДНК исходного сайта, а не вводит новую дизайн-систему. Сохраняются тёплая Lace-основа, Dutch White, шалфейный зелёный, Thistle, Fraunces, камерные портреты, центрированная подача и мягкие скругления. Современность достигается типографической аккуратностью, ритмом и состояниями компонентов.

## Компоненты

- Primary button: компактная плоская заливка Reseda, высота 46 px, радиус 14 px, шрифт Fraunces нормального начертания; без градиента, глянца и тени. Hover становится темнее.
- Secondary button: лёгкая полупрозрачная заливка с тонким контуром и тем же спокойным шрифтом; text button используется только для навигационных переходов.
- Navigation: Fraunces вместо тяжёлого интерфейсного гротеска, нормальное начертание и больше воздуха между пунктами; CTA в шапке — контурный, а не залитая капсула.
- Topic cloud: темы оформлены как лёгкие типографические плашки разного масштаба с тонким контуром. Под облаком остаются короткие текстовые пояснения для ясности и SEO.
- CTA: один главный текст «Записаться на консультацию»; каналы связи раскрываются на странице контактов.
- Cards: мягкие светлые поверхности с исходным радиусом 22 px используются для форматов, тарифов и компактных trust facts. Жизненные контексты оформлены текстовыми блоками с разделителями.
- Forms: не добавляются без рабочего обработчика и отдельного согласия на сбор данных.
- Spacing: 68–96 px между крупными desktop-секциями, 56–76 px на мобильных — ближе к ритму исходного сайта.
- Focus: контрастный двухпиксельный outline; touch-target не меньше 44 px.
- Motion: короткие hover/focus-переходы; `prefers-reduced-motion` отключает анимацию.

## Адаптивность

Hero и заголовки центрированы на всех основных страницах, портрет расположен под главным сообщением, как в исходной версии. Навигация сворачивается в доступное меню. Сетки контекстов, форматов и цен становятся одноколоночными без горизонтального скролла.
